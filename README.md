# AI SEO Blog & Content Cluster Generator

This project is an AI-powered SEO content generation system that helps businesses create:
- SEO blogs
- Keyword ideas
- Content clusters
- Local SEO articles

The project uses prompt engineering and AI tools like ChatGPT to generate high-quality content for websites and blogs.

---

# Features

- SEO Blog Generation
- Keyword Research
- Content Cluster Creation
- Local SEO Content
- AI Prompt Engineering
- Markdown-based Documentation

2. Generate content using ChatGPT
3. Save outputs in `.md` files
4. Upload files to GitHub
5. Organize screenshots in assets folder
